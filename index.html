Multi-Computer Sync

Keep this jobsite's data in step across computers. Optional — the app works fully offline without it.

Newest change wins across computers. If two people edit the same day on different computers, whoever saves last is kept — so it's best to have one person drive per day.

How to set this up (one time, about 5 minutes)
  1. Go to script.google.com and click New project.
  2. Delete the sample code. Click Copy Apps Script code below and paste it in.
  3. Click Deploy → New deployment. Choose type Web app. Set Execute as: Me and Who has access: Anyone. Click Deploy and authorize when asked.
  4. Copy the Web app URL it gives you. Paste it in Sync URL above, name this computer, and click Connect & Sync.
  5. On any other computer, open this app, tap the save chip to open this window, paste the same URL, and Connect.
